## 1. Описание проекта

В работе исследуется обучение многослойного перцептрона (MLP) на синтетическом наборе данных `make_moons`. Сравниваются шесть конфигураций нейронной сети (A–F), различающихся функцией активации, способом инициализации весов, оптимизатором и количеством скрытых слоёв.

Для каждой конфигурации обучение выполняется с двумя значениями seed: `11` и `29`. Используются обучающая, валидационная и тестовая выборки. По среднему значению validation loss выбирается одна конфигурация; тестовая оценка проводится только для выбранной модели.

## 2. Использованное оборудование и программное окружение

Эксперименты выполнялись на CPU:

## 3. Конфигурации экспериментов

Во всех конфигурациях используется 32 нейрона в каждом скрытом слое, два выходных логита, 100 эпох обучения и размер батча 128.

| Конфигурация | Скрытые слои | Функция активации | Инициализация весов | Оптимизатор |
|---|---:|---|---|---|
| A | 6 × 32 | Sigmoid | Xavier normal | Adam, lr = 0.003 |
| B | 6 × 32 | Tanh | Xavier normal | Adam, lr = 0.003 |
| C | 6 × 32 | ReLU | Xavier normal | Adam, lr = 0.003 |
| D | 6 × 32 | ReLU | He normal | Adam, lr = 0.003 |
| E | 6 × 32 | ReLU | He normal | SGD, lr = 0.05 |
| F | 1 × 32 | ReLU | He normal | Adam, lr = 0.003 |

Каждая конфигурация запускается с двумя seed: `11` и `29`. Таким образом, всего выполняется 12 запусков.

## 4. Установка

Для запуска рекомендуется использовать Python 3.12 и виртуальное окружение.

Создание и активация виртуального окружения в Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```
Установка зависимостей:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Для запуска ноутбука в Jupyter Notebook при необходимости установите Jupyter:
```bash
python -m pip install notebook
```

5. Запуск
Запустите Jupyter Notebook из корневой папки проекта:
jupyter notebook

Откройте файл notebook.ipynb и выполните ячейки последовательно сверху вниз. Ноутбук создаёт каталоги results/, figures/ и checkpoints/, сохраняет метрики экспериментов, графики и выбранную модель.

Эксперименты рассчитаны на выполнение на CPU. Для воспроизведения исходного режима в ноутбуке используется один вычислительный поток PyTorch.
